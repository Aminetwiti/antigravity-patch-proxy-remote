MITM Proxy

Manage the local TLS proxy and CA certificate

MITM on port 443 required for Antigravity 2.2.x – 2.4.x (up to 2.4.2)
Antigravity 2.2.x, 2.3.x, and 2.4.x (up to 2.4.2) require MITM on port 443. Without it, the language server fails with 127.0.0.1:443 refused. Make sure the proxy is listening on 443 and the CA certificate is installed.
